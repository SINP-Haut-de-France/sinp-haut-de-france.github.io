# Plateforme technique du SINP Hauts de France.

Documentation technique et suivi des mises à jour de la plateforme technique sinp des Hauts-de-France

## Notes de version (Release Notes)

La release note ou note de version est un document qui décrit les modifications apportées à un logiciel ou un système, généralement lors d'une mise à jour ou d'une nouvelle version. Elle fournit des informations détaillées sur les nouvelles fonctionnalités, les corrections de bugs, les améliorations et les changements importants qui ont été introduits dans la version actuelle.
La version initiale de la plateforme pour la première phase de test est la version 1.0.0. La prochaine version 1.0.1 intègrera de nouvelles fonctionnalités mais également des correctifs et évolutions. La note de version détaillera tous ces changements.
